# 😺NKD Arrow

A curved arrow you place by hand, for showing flow between two parts of a graph without
writing anything. The node itself is a small dot and the arrow always passes through it.

## Settings

- Double-click the dot to edit it.
- **From**: where the arrow starts. Leave it empty and the arrow starts at the dot.
- **To**: the node, widget or group it points at.
- **Label**: optional text beside the dot.
- **Color**: the arrow's colour.
- Drag the dot to bend the curve.
