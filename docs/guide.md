# 😺NKD Guide

The table of contents of a workflow. It plays the numbered [hints](hint.md) as a tour, lists
every note, zone and group, and exports all of it as a Markdown document.

## Buttons

- **Start tour**: plays the hints that have a tour step, lowest number first. The camera flies to each one and its panel shows *Prev*, *Next* and the step count.
- **Contents**: opens a panel with the tour steps, the other notes, the zones and the groups. Click an entry to jump to it.
- **Export Markdown**: downloads a `.md` file with the tour first, then the other notes, each with the targets it points at.
- **Offer tour on open**: when someone opens the workflow, a bar offers to start the tour. It shows once per tour on each browser.

## During a tour

- Right and Left arrow keys step forward and back.
- Esc ends the tour.
- *Finish* on the last step closes it.

The Guide's title is the title of the tour and of the exported document.
