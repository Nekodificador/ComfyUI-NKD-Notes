# 😺NKD Zone

A dashed, labelled frame for highlighting an area of the graph. Unlike a group it doesn't carry
the nodes inside it along when you move it, and only its label strip and border can be grabbed,
so everything inside stays clickable.

## Settings

- Double-click the label strip to edit it.
- **Label**: the text at the top left.
- **Color**: frame and label colour.
- Drag the bottom-right corner to resize it.
